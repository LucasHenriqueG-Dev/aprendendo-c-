# Exercício 010 - Mega-Sena

Assunto: comparação entre dois vetores  
Status: concluído

## Enunciado

Faça um programa em C# que confira uma aposta da Mega-Sena:

- a) leia e armazene em um vetor as **6 dezenas sorteadas**;
- b) leia a **quantidade de dezenas jogadas** e crie um vetor com esse tamanho;
- c) leia e armazene as dezenas apostadas;
- d) conte quantas dezenas da aposta foram sorteadas (**acertos**);
- e) exiba os dois vetores e a quantidade de acertos.

## O que pratiquei

- Vetor de tamanho fixo e vetor de tamanho informado pelo usuário
- Laços `for` aninhados para comparar todos os elementos de dois vetores
- Contador de acertos
