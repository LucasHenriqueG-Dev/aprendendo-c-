# Exercício 001 - Loja de Bicicletas

Assunto: variáveis, operações aritméticas e condicionais  
Status: concluído

## Enunciado

Uma loja vende bicicletas com um acréscimo de 50% sobre o seu preço de custo. Ela paga a cada vendedor 2 salários mínimos mensais, mais uma comissão de 15% sobre o preço de custo de cada bicicleta vendida, dividida igualmente entre eles. Para isso, é necessário solicitar:

- a) o número de empregados da loja;
- b) o valor do salário mínimo;
- c) o preço de custo de cada bicicleta;
- d) o número de bicicletas vendidas.

Em seguida, deve-se calcular e exibir:

- a) o salário final de cada empregado;
- b) o lucro (líquido) da loja.

Quais os cálculos necessários que devem ser feitos?

## O que pratiquei

- Leitura de dados com `Console.ReadLine()` e conversão com `int.Parse` / `double.Parse`
- Cálculo de porcentagem e operações aritméticas
- Estrutura condicional `if` / `else if` / `else` (lucro, prejuízo ou empate)
