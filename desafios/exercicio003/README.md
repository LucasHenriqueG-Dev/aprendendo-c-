# Exercício 003 - Calculadora

Assunto: laço de repetição e menu de opções  
Status: concluído

## Enunciado

Uma calculadora simples deve realizar operações matemáticas básicas entre dois números informados pelo usuário. Para isso, é necessário:

- a) solicitar os dois números que serão utilizados nas operações;
- b) exibir um menu com as opções de soma, subtração, divisão e multiplicação, além da opção de encerrar o programa;
- c) realizar a operação escolhida pelo usuário e exibir o resultado;
- d) repetir a exibição do menu até que o usuário opte por encerrar o programa (digitando 0).

Como evitar que o programa trave ao tentar dividir um número por zero?

## O que pratiquei

- Laço `while` controlado por uma opção do usuário
- Menu com `if` / `else if` / `else`
- Comando `break` para sair do laço
- Verificação para não dividir por zero
