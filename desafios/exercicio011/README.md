# Exercício 011 - Busca em Vetor Preenchido

Assunto: vetores e contadores  
Status: concluído

## Enunciado

Faça um programa em C# para percorrer um vetor `V` de números inteiros e verificar quantas vezes um determinado valor `x` está presente no vetor. O valor de `x` deve ser informado pelo usuário. Considere que o vetor já foi criado e preenchido.

## O que pratiquei

- Vetor inicializado direto no código (`int[] v = { ... };`)
- Percorrer um vetor com `for`
- Contador de ocorrências

## Como rodar

```bash
cd desafios/exercicio011
dotnet run
```
