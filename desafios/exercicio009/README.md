# Exercício 009 - Ocorrências de X

Assunto: vetores e contadores  
Status: concluído

## Enunciado

Faça um programa em C# que:

- a) leia o tamanho `N` do vetor;
- b) leia e armazene `N` números inteiros;
- c) leia um valor `X`;
- d) informe **quantas vezes** `X` aparece no vetor.

## O que pratiquei

- Percorrer um vetor com `for`
- Comparação de cada elemento com um valor
- Contador (`cont++`)
