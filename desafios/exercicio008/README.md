# Exercício 008 - Soma e Média de um Vetor

Assunto: vetores e acumuladores  
Status: concluído

## Enunciado

Faça um programa em C# que:

- a) leia um valor `N`;
- b) leia e armazene `N` números inteiros em um vetor;
- c) calcule e exiba a **soma** dos valores;
- d) calcule e exiba a **média** dos valores.

## O que pratiquei

- Criação de vetor com tamanho informado pelo usuário
- Acumulador (`soma += v[i]`)
- Conversão `(double)` para evitar a divisão inteira no cálculo da média
