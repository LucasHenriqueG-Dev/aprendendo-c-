## Organização

Cada exercício fica em uma pasta dentro de `desafios/`, com:

- `README.md` com o enunciado
- `Program.cs` com a minha solução
- o arquivo `.csproj` do projeto

## Como rodar

Precisa ter o [.NET SDK](https://dotnet.microsoft.com/download) instalado. É só entrar na pasta do exercício e rodar:

```bash
cd desafios/exercicio001
dotnet run
```
